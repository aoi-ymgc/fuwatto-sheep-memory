# ふわっとひつじの神経衰弱

オリジナルの54枚トランプを主役にした、ブラウザで遊べる1人用神経衰弱ゲームです。

## 制作目的

オリジナルキャラクターとトランプを生かし、Webデザイナーのポートフォリオにも掲載できるゲーム作品として制作しました。将来は同じカード基盤を使い、ババ抜き・ブラックジャック・大富豪などへ展開できます。

## 使用技術

- HTML / CSS / JavaScript（ES Modules）
- CSS Grid、3D `rotateY()` カードフリップ
- Web Audio API（効果音）
- localStorage（難易度別ベストスコア）
- Cloudflare Workers Static Assets 用 `wrangler.jsonc`

公開用ファイルは `npm run build` で `public/` に生成します。開発用のJavaScriptや設定ファイルは公開対象に含めません。

## ルール

- ♠と♣は、同じランク同士で黒ペアです。
- ♥と♦は、同じランク同士で赤ペアです。
- Jokerは2枚で1ペアです。
- 例：♠7 + ♣7 は正解、♠7 + ♥7 は不正解です。

## 工夫したポイント

- `js/deck.js` に54枚のカードデータ、ペアID、シャッフル、難易度別のペア単位抽出を集約しました。
- `js/game.js` は神経衰弱固有の判定と状態を担当し、カードの基本データ・フリップ表示・ストレージは分離しています。
- EASY / NORMAL / HARD / FULL DECK の4段階を用意し、毎回ペアを崩さずランダム配置します。
- TIME、実際にめくった枚数であるFLIPS、MATCH数、S〜Cランク、Joker専用演出を搭載しています。
- 完成済みカードをイラスト込みの自己完結WebPへ最適化して使用。SVG内の外部PNG参照に依存しないため、初回反転でもキャラクターまで確実に表示されます。
- 連続正解・連続ミスには3段階の短い演出を用意し、ゲームの手応えを高めています。

## レスポンシブ対応

320px幅から横スクロールなしで遊べます。盤面はEASYでは4列、通常は6列、スマートフォンでは4列へ切り替わります。キーボードのTab / Enter / Spaceでもカードを選択でき、`prefers-reduced-motion` も考慮しています。

## Cloudflareへの公開

1. このフォルダをCloudflare Workersプロジェクトとして開きます。
2. `wrangler.jsonc` の `name` を必要に応じて変更します。
3. `npm run build` を実行し、公開用の `public/` を生成します。
4. `npm run deploy`（または `npx wrangler deploy`）を実行します。

DBやサーバーは不要です。将来のランキングは、カードIDとゲーム結果の構造を保ったままWorkers / D1等を追加できます。
